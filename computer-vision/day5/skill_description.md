# 5일차 스킬톤 제출: `oz-assignment-submit`

## 스킬 설명

**언제 입력하나:** "&lt;트랙명&gt; N일차 진행하자" (예: "컴퓨터비전 6일차 진행하자") 라고 말하면 트리거됩니다.

**무엇을 하나:** OZ 코딩스쿨 부트캠프 과제 제출 워크플로우 전체를 자동으로 처리합니다.
1. Notion에서 해당 N일차 제출란의 내 상태(시작 전/진행 중/완료)를 확인
2. 시작 전이면 과제 스펙을 파악 (외부 강의자료 링크 우선 확인 → 없으면 완료한 급우 제출물로 역추적)
3. 실제 데이터를 구해 실제로 모델을 학습/실행 (가짜 수치 절대 금지)
4. 결과를 HTML 리포트 또는 캡처 이미지로 정리
5. GitHub(`moyajong/oz-ai-06`)에 코드+결과를 커밋/푸시
6. Notion 필수 과제 블록에 GitHub 링크를 임베드
7. 상태를 완료로 변경

**어떤 결과를 받나:** 마지막에 아래 형태의 완료 요약을 받습니다.
```
N일차 완료: 커밋 <해시> · <핵심 결과 한 줄> · Notion 완료 처리됨
```
그리고 실제로 완료 처리된 Notion 페이지와 GitHub 커밋을 바로 확인할 수 있습니다.

## 실사용 예시 (오늘 6일차에 실제로 테스트함)

**입력:** "컴퓨터비전 6일차 진행하자"

**받은 결과:**
```
6일차 완료: 커밋 1e9c178 · Brain Tumor MRI 데이터 함정 진단 —
meningioma 공식 test 정확도가 증강 이미지 혼입으로 부풀려져 있음을
실측 확인(공식 F1 0.9382 vs 원본만 0.9199), 베이스라인 acc 95.06%
· Notion 완료 처리됨
```

이 스킬은 이 세션에서 컴퓨터비전 1~6일차 전체를 반복 수행하며 관찰한 실제 워크플로우를
`skill-maker-interview` 스킬로 인터뷰하여(9개 질문) 요구사항을 정리한 뒤 작성했고,
6일차 과제에 실전 투입해 정상 동작을 확인했습니다.
